# Fables LP 实验室

本机运行的 Fables 流动性规划工具：查询池子、计算区间代币配比、比较 APR 收益，并模拟跌出区间后的无常损失。

这是独立项目，与 Fables 无隶属关系。仅提供规划与测算，不连接钱包、不导入私钥、不签名、不提交加池交易。

## 快速开始

1. 安装 **Python 3.9 或以上版本**，下载入口：[Python 官网](https://www.python.org/downloads/)。
2. 将 ZIP **完整解压**，不要在压缩包内直接双击运行。
3. Windows 用户双击 `启动工具.cmd`；也可在解压后的目录运行 `python start.py`。macOS / Linux 可使用 `python3 start.py`，这些系统未做完整桌面启动验证。
4. 浏览器打开 [本机工具](http://127.0.0.1:8767/)。读取实时数据需要联网。

不需要 npm、API Key 或额外 Python 包。服务只监听本机地址。关闭启动窗口后服务继续运行；电脑重启后再次运行启动文件。重复启动会复用本工具的已有服务；其他程序占用端口时会提示。

## 功能

- 读取公开池子目录、TVL、24 小时成交量、LP 手续费和已知 APR，默认每 30 秒刷新。
- 根据资金与价格区间计算两币数量和美元价值比例，处理不同小数位、代币顺序和显示倍率。
- 区分整体池子 APR、所选区间 APR 和手动 APR 情景。
- 比较 10 分钟、30 分钟、1 / 4 / 8 / 12 / 24 小时、15 / 30 天的单利收益。
- 模拟区间内外价格变化，分别显示无常损失、本金盈亏及收入与成本后的盈亏。
- 保存最多 60 个方案到当前浏览器，导出 CSV。
- 优先展示本地缓存，空值或断网时标明缺失 / 未更新，不用演示价格冒充实时行情。

## 示例流程

选择 ETH/USDG → 输入 $1,000 → 设定最低价与最高价 → 查看所需 ETH 与 USDG 数量 → 选择 APR 口径 → 查看各时段收益。

在“无常损失”模块输入假设跌后价格，或点击“下界再跌 10%”。模块保持初始流动性不变，对比 LP 与原配比直接持有的价值；本金亏损和无常损失分开显示。

示例金额只是操作示例。价格、奖励与池子数量取决于上游数据，不是固定报价。

## 数据与计算限制

API 和 RPC 查询会向 Fables / RPC 服务发送网络请求。用户填写的资金、价格假设和本地方案不会作为这些查询的参数上传。本工具没有遥测或 GitHub 上传功能。

收益按固定 APR、365 天单利测算；不会预测未来费率、奖励持续时间或价格路径。收益表不包含币价盈亏和无常损失；无常损失模块单独计算。跨币池和稳定币估值假设见使用说明。

Fables 的公开接口未承诺对本工具保持兼容。接口改版、限流、网络故障或奖励资料缺失时，部分数据可能暂不可用。
